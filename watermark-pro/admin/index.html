Finalized System Rules

✓ Downloads are the permanent ranking metric.
✓ Uploads are not used for Top Users.
✓ User names only — no usernames/handles. Min 2 chars, max 30 chars.
✓ Avatar uses URL only — no file upload.
✓ Default avatar letter reflects user's actual name in real-time.
✓ Verified badge is beside the user's name.
✓ Badge shape uses bg.jpg as texture.
✓ Tick inside badge is always white.
✓ Same verified badge is used everywhere, including Admin.
✓ Top Users includes both Free and Pro users.
✓ User can hide themselves from Top Users.
✓ Admin dashboard shows full names (not masked).
✓ Account Created is shown to both User and Admin.
✓ Subscription remains monthly.
✓ Admin can set normal price and discounted price directly.
✓ Payment requires a generated reference.
✓ No payment screenshot upload is required.
✓ Admin manually verifies transaction reference.
✓ Approval activates Pro for one month.
✓ Expiring status turns yellow (badge still visible).
✓ Expired status turns red and shows how long ago it expired.
✓ Receipt downloadable after payment — status PENDING until admin approves.
✓ Status becomes PAID only when admin approves.
✓ Admin can grant free Pro access for custom duration (1–12 months).
✓ Admin can update payment QR via URL.
