# UI decisions, September 2026

- Charcoal navigation is the only persistent dark surface, so orientation stays obvious without separators.
- Warm paper and white content objects distinguish reading areas through surface contrast instead of repeated rules.
- The lime accent is reserved for the current location and the create-post action, so it remains a genuine focal cue.
- Arimo remains the typeface because it is the established, compact product voice.
- The feed uses spaced post objects because each post is a distinct social object; settings and subscription use fewer, larger action surfaces rather than a repeated card grid.
- Motion remains limited to existing state transitions, with reduced-motion support, so the feed stays quiet while interactions remain legible.
