# Legacy UI archive

Archived on 2026-09-03 before the new UI was introduced.

All files were moved without changing their internal contents or directory structure.

## Main reference points

- `index.html` — previous main UI entry point
- `admin.html`, `admin/`, `admin-live.css`, `admin-live.js` — previous admin UI
- `login.html`, `login/` — previous login UI
- `website-account-shell.css`, `website-account-shell.js` — previous account shell styling and behaviour
- `firebase-config.js`, `firebase.json`, `database.rules.json`, `functions/` — previous Firebase configuration, rules, and backend logic
- `pwa.js`, `sw.js`, and the manifest files — previous PWA behaviour
- `watermark-pro-account-system-v29.html` and `watermark-pro-account-system-v82.html` — retained historical account-system builds
- Images, icons, ZIP files, `.firebase/`, and `tmp/` are retained as found

When rebuilding the new UI, refer back to this folder for behaviour and business logic that may not be represented correctly in the new screens.
